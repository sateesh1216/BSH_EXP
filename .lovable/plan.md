
## UI Modernization Plan

### 1. Dashboard Home Screen
- Refresh summary cards with glassmorphism effects, subtle gradients, and improved spacing
- Better greeting section with user avatar and time-based greeting
- Improved section headers with animated transitions
- Cleaner card hover effects and visual hierarchy

### 2. Login / Auth Pages
- Modern centered card layout with gradient background
- Polished form inputs with better focus states
- Add branding/logo area with app name styling
- Improved error/success message styling
- Smoother transitions between sign-in/sign-up/request access tabs

### 3. Admin Panel
- Refreshed sidebar with better active state indicators
- Modernized stats cards on admin dashboard
- Improved table styling with better row hover effects
- Consistent card styling with subtle borders and shadows

### Design Approach
- Keep existing functionality intact — purely visual improvements
- Use existing design tokens from the theme system
- Maintain light/dark mode compatibility
- Keep responsive behavior working on mobile
